# Google MediaPipe – Android

An Android application demonstrating **Google MediaPipe** integration for real-time computer vision and hand tracking.

## 📱 Overview

This project explores the integration of **MediaPipe Hand Landmarker** into an Android application.

The application detects and tracks hands using the device camera and processes hand landmarks in real time.

## ✨ Features

- 🤚 Real-time hand detection
- 📍 Hand landmark tracking
- 📷 Camera-based processing
- ⚡ Real-time MediaPipe processing
- 📱 Android application built with Kotlin
- 🧩 MediaPipe Tasks Vision integration

## 🛠️ Technologies

- **Kotlin**
- **Android**
- **Google MediaPipe**
- **Hand Landmarker**
- **Camera**
- **Jetpack Compose**
